# Nokto 2.0.1 — corrección de errores

Esta actualización de mantenimiento corrige problemas detectados en Nokto 2.0:

- La isla inicia con el modo elegido en Ajustes aunque Windows conserve argumentos de bandeja antiguos.
- Los controles de la isla no quitan el foco a una aplicación en pantalla completa.
- La reproducción no desaparece durante los cambios breves de sesión entre canciones.
- El seguimiento ocular filtra pequeñas variaciones del cursor para evitar temblores.
- El portable estable comprueba actualizaciones públicas; el canal DEV deja sus controles de actualización desactivados y explícitos.

No incluye funciones nuevas.
